# How AURELLE sections will sell

Use an actual paid Shopify store and Shopify Digital Products. Github Pages hosts only the marketplace website and product pages.

1. Install Shopify Digital Products on the intended selling store.
2. Create a digital product with the tested section name, price and accurate description.
3. Upload the corresponding private ZIP package to the digital product.
4. Enable automatic file delivery after payment.
5. Test purchase and email/download delivery.
6. Add real price, Shopify product URL (checkoutUrl), preview screenshot, shopifyTested:true and published:true to data/collections/aurelle.json.
7. Copy live, verified products into data/sections.json for homepage searches.

Never commit paid ZIP files, direct download URLs or API secrets to this public repository.

Shopify docs: https://help.shopify.com/en/manual/products/digital-service-product/digital-downloads
